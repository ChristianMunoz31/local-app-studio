# Code of conduct

This project follows the Contributor Covenant, version 2.1. The full text is at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/ and applies to
every space for this project: issues, pull requests, discussions and any other
channel where someone speaks for the project.

In short: be respectful, assume good faith, give and accept feedback with
courtesy, and do not harass anyone.

## Enforcement

Report unacceptable behavior to the maintainer through <CONTACT_METHOD>. Reports
are handled privately. The maintainer follows the Enforcement Guidelines in the
Contributor Covenant text linked above.
